# Markdown đã xử lý

Đặt các file Markdown chuyển từ PDF vào thư mục này rồi chạy `npm run parse:markdown`.
Parser sẽ tạo `data/64-que.json` và in danh sách quẻ còn thiếu để kiểm tra thủ công. Các PDF gốc hiện nằm trong `Data_Sach`; ảnh scan nằm trong `Data_Photo` và sẽ được dùng ở Giai đoạn 2 cho pipeline OCR.
